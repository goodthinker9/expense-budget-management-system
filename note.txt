React Router provides an important component called:

<Outlet />

Think of it as a placeholder:

MainLayout
│
├── Navbar
├── Sidebar
│
└── <Outlet />
       ↑
       current page appears here

If the user visits:

/dashboard

the Dashboard component appears inside <Outlet />.
<Route element={<MainLayout />}>

means “use MainLayout as the common layout for the routes inside me.”

Why wrap the routes?

Because these pages all need the same:

Navbar
Sidebar

So instead of doing:

<Route path="/dashboard" element={
    <MainLayout>
        <Dashboard />
    </MainLayout>
} />
